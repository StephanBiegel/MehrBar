1. `DesktopHost.Find()`: EnumWindows and return the top-level window that has a SHELLDLL_DefView child (Progman on 24H2+/26200, WorkerW on older builds) with its class name; called fresh every time, never cached (Explorer restarts recreate it). `IsAbove(bar)`: walk GetWindow(bar, GW_HWNDPREV) upward; true when the desktop host is above the bar.
2. `ZOrderGuard.cs` ([HostVariant("S0", "S1", "S2")]) — re-implement the procedure from RESEARCH Pattern 2 in our own code; do not open or copy Rainmeter source (licence GPL-2.0, while MehrBar is meant for a later public MIT release):
   - S0: hook WM_WINDOWPOSCHANGING and force hwndInsertAfter = HWND_BOTTOM unless SWP_NOZORDER is set (concept Q10 follow-up "Z-Reihenfolge wird bei jeder Positionsänderung erzwungen").
   - S1: S0 plus SetWinEventHook(EVENT_SYSTEM_FOREGROUND, WINEVENT_OUTOFCONTEXT | WINEVENT_SKIPOWNPROCESS) on the UI thread (it has a message loop; keep the delegate in a static field, Pitfall 7) and a DispatcherTimer at 250 ms (100 ms while shown). On each callback/tick: if DesktopHost.IsAbove(bar) -> state shown -> SetWindowPos(HWND_TOPMOST, SWP_NOMOVE|SWP_NOSIZE|SWP_NOOWNERZORDER|SWP_NOACTIVATE|SWP_NOSENDCHANGING); when no longer shown -> HWND_NOTOPMOST then HWND_BOTTOM. Log every transition with a timestamp (event names per interfaces block).
   - S2: like S1 detection, but instead of topmost re-insert the bar directly above the desktop host (hwndInsertAfter = the window just above the host) — used in 01-14 only if S1 fails D-11.
   - All strategies: register for TaskbarCreated (RegisterWindowMessage) and WM_DISPLAYCHANGE (re-find host, re-assert), WTSRegisterSessionNotification for WM_WTSSESSION_CHANGE (log only); option `log-events true` additionally hooks EVENT_SYSTEM_* and EVENT_OBJECT_REORDER for logging only (which signal does Win+D send on 26200?).
   - The bar stays at layer bottom; topmost is only the watcher's temporary state (D-12).
3. `ZOrderCase.cs` ([DriverCase("zorder")]) with trigger `none` first: per guard × trigger × rep — StartHost("--variant H1,<guard> --log-events true"); StartWitness("partial") (covers probes 3 and 4 only); real runs call DesktopPrep.ClearTopArea before starting host/witness and bring the witness to the foreground; GapSampler samples probes 1, 2, 5 every 10 ms from trigger until +3 s (gap = first..last sample without sentinel; returned = sentinel visible again by itself at the end); after the trigger's Undo the CoverTest samples probe 3 every 10 ms for 3 s while the witness is restored and visible: every sample showing sentinel instead of cover colour counts as in-front (D-11: must be 0; 1–2 samples = borderline for Stephan, D-08); z-order snapshots (redacted committed, full private) at T+0, 0.5, 1, 2 s. `--dry-run`: no ClearTopArea, no foreground change, trigger `none` only; sample once, assert host READY, guard-start and desktop-host rows exist; print `ZORDER DRY OK <guard>`.
4. Topic list q2 only for names missing elsewhere (e.g. SetWinEventHook constants not yet listed, WTS names, HWND_NOTOPMOST if absent).

Implement each trigger as IZTrigger; every mutating trigger registers its undo with the SafetySession BEFORE firing (Pitfall 3):
- `win-d`: Chord(LWIN, D); undo = Chord(LWIN, D) again.
- `corner`: read HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced value TaskbarSd (remember absent/value), set 1, broadcast WM_SETTINGCHANGE with "TraySettings"; restore = original value (delete when it was absent) + broadcast. Corner point from FindWindow("Shell_TrayWnd") + GetWindowRect (far end of the taskbar on its edge, not assumed). Fire = click the corner; undo = click it again. If the click does not show the desktop (desktop host not above the bar afterwards), log `corner-inactive` once and restart Explorer once via the `explorer` trigger logic before retrying.
- `win-m`: Chord(LWIN, M); undo = Chord(LWIN, LSHIFT, M).
- `peek`: requires the corner setting as above; move to the corner, hover 2 s, move away; second variant `peek-key` holds Win+, (comma) for 2 s.
- `alt-tab`: Alt down, Tab, 500 ms, Tab, Alt up; then check that the bar still has WS_EX_TOOLWINDOW and is not foreground (bar must not appear in Alt+Tab; the visual list check is hand part H3).
- `explorer` (needs `--allow-explorer`): `taskkill /f /im explorer.exe`; wait up to 5 s for an automatic restart (Shell_TrayWnd + desktop host present), else start explorer.exe; sample for 10 s after Shell_TrayWnd reappears; restore = ensure explorer.exe runs.
- `display` (needs `--allow-display`): back up the desktop icon layout with `reg export HKCU\Software\Microsoft\Windows\Shell\Bags\1\Desktop` to `RepoPaths.PrivateResults/desktop-bags-<ts>.reg`; pick a different supported mode via EnumDisplaySettings (prefer 1600x900, else 1280x720, same frequency); register restore = ChangeDisplaySettingsEx(null, …) (returns to the registry mode); ChangeDisplaySettingsEx(mode, flags 0 = dynamic, not persisted) for 3 s, then undo.
- `lock` (needs `--allow-lock`, used only by hand part H2): LockWorkStation, then poll OpenInputDesktop until it succeeds (= unlocked by Stephan) and sample at T+0, 0.5, 1, 2 s after unlock.
- `manual`: inject nothing; sample continuously for `--seconds` (watchRealInput false) so Stephan can press the real keys (D-07, hand part H3).
- `none`: no-op.
Wire `--trigger all` = win-d, corner, win-m, peek, alt-tab (+ explorer/display only with their allow flags). `--list-triggers` prints all names. Dry runs for S0 and S2 with trigger none.
