<interfaces>
Core API created here (namespace MehrBar.Core.Layout; axis-neutral: `u` runs along the bar, "before" = smaller u, "after" = larger u):
- public enum ZoomAnchorMode { Cursor, Center }
- public readonly record struct ZoomParams(double IconSize, double ZoomSize, double Radius)
- public readonly record struct RestItem(double Start, double Length, bool Zooms)   // separators: Zooms = false
- public sealed record ZoomResult(double ExtraBefore, double ExtraAfter, IReadOnlyList<double> DisplayedStarts, IReadOnlyList<double> DisplayedLengths)
- public static class ZoomKernel { public static double Factor(double distanceInPitches, double radius); }   // (cos(pi*d/r)+1)/2 for d < r, else 0
- public static class ZoomEngine { public static ZoomResult Compute(IReadOnlyList<RestItem> items, double pitch, ZoomParams p, double pointerU, ZoomAnchorMode anchor); }
Model (RESEARCH "Q5", docs/PROJEKT_START.md section 6): distance d_i = |pointerU − rest centre_i| / pitch from REST positions (never displayed ones); extra_i = (ZoomSize − IconSize) * Factor(d_i, r) for zooming items, 0 for separators; Cursor: the item whose rest extent contains pointerU splits its extra by the pointer's fraction f inside it (before share = f * extra), all other extras go wholly before/after; displayed bar = [restStart − ExtraBefore, restEnd + ExtraAfter]; Center: ExtraBefore = ExtraAfter = total/2.

Measured inputs (independent of the bar edges under test):
- Pointer fraction per row: the cursor icon keeps the pointer point fixed, so its displayed centre moves by (0.5 − f) * extra_c relative to its rest centre; with the cursor icon's glyph centre measured in the rest image (image 1) and the zoomed image (pixel-aligned per the Nachtrag), f = 0.5 − (displayedCentre − restCentre) / (ZoomSize − IconSize). Only the cursor icon's own pixels enter this value.
- Radius: from the widths (or centre-to-centre spacing) of the direct neighbours and next-but-one icons in the "Maus mittig" image, solving size = IconSize + (ZoomSize − IconSize) * Factor(d, r) for r; the bar edges never enter this value.
</interfaces>
