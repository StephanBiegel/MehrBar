  <action>
Implement `HitCase` ([DriverCase("hit")]) for one variant path first (H1), structured so Task 2 only adds variants:
1. Click plan from `--seed`: `--clicks` points inside ScreenPlate (uniform, 2 px away from the border) and the same number outside, split evenly over five categories: 1 px left, right, above, below the plate (random positions along the edge) and the zoom-overhang gap (window-relative rectangle x 650..1250, y 70..240, alpha 0). Interleave inside/outside so that two consecutive outside clicks are at least SM_CXDOUBLECLK/SM_CYDOUBLECLK apart, and wait GetDoubleClickTime() + 100 ms between any two clicks (a double-click on a desktop icon could launch something). Never right-click outside the plate.
2. Real run (not dry, not manual): BeginSafety(10 min) -> DesktopPrep.ClearTopArea -> StartWitness("none") at a neutral spot and BringToForeground -> StartHost("--variant <v>") -> for every planned click: re-assert witness foreground, Input.Click, wait 250 ms, read new host CSV rows; inside = captured when an `lbuttondown` row arrived and foreground is still the witness; outside = passed through when no host row arrived (positive evidence: foreground moved to the desktop host, recorded as an extra column). Also sweep the mouse across the plate and outside it and compare the host `counters` MouseMove deltas. Record WindowFromPoint at each outside point as an extra data point only (assumption A2).
3. `--dry-run`: build the click plan, start host H1 and witness (cover none), take one foreground + z-order sample, send NO input, write the planned clicks to the CSV, print `HIT DRY OK <variant>`.
4. `--manual --seconds N`: start host + witness, inject nothing, log every host click row with the foreground at that moment for N seconds (used by hand part H1, D-07), print running totals.
5. Write per-click rows to `--out` (redacted: no foreign window titles) and the summary table (interfaces block) to `--summary-md`. Exit 0 when the run completed (a poor capture rate is a result, not an error); exit 1 only for harness failures.
