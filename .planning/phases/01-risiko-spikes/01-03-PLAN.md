<interfaces>
WindowHost CLI (consumers 01-07, 01-09..01-12, 01-17 rely on these names): `--role bar|witness` (default bar) · `--variant <name>[,<name>…]` (default H1) · `--size WxH` (default 1900x250) · `--pos x,y` (default top centre of the primary monitor, y = 0) · `--transparent true|false` (default true; false = opaque #202020 background, used by the Q4 control run) · `--render hw|sw` (default hw; sets RenderOptions.ProcessRenderMode BEFORE the first window and logs the effective mode and RenderCapability.Tier) · `--sentinel on|off` (default on) · `--cover full|partial|none` (witness only) · `--title <text>` · `--log <csv>` (default RepoPaths.DryResults/host-<pid>.csv) · `--exit-after-ms N` · `--list-variants`. Every other `--key value` lands in HostContext.Options. On startup the host prints exactly one stdout line `READY hwnd=0x<hex> pid=<n> role=<bar|witness>`.

IHostVariant { void Attach(HostContext ctx, string name); void Detach(); } with [HostVariant(params string[] names)]; VariantRegistry discovers implementations by reflection.
HostContext: Window (HostWindow), Hwnd (HWND), Options (IReadOnlyDictionary<string,string>), Log (RunLog), Plate (Rect in window px), ScreenPlate (RECT in screen px), Root (Canvas the variant may add children to), Counters (MessageCounters), AddHook(HwndSourceHook).
Host CSV rows (RunLog header ts_ms,case,variant,guard,event,detail; ts_ms = Stopwatch ms since process start; RFC 4180 quoting; flushed per line): `lbuttondown x,y`, `rbuttondown x,y`, `rbuttonup x,y`, `mouseactivate x,y` (immediately), `counters move=… poschanging=…` (every 250 ms when changed), `self-check exstyle=… bottom=true|false below=<class|none>`, `first-frame zindex=… below=<class|none>`, `render-mode effective=… tier=…`.
SpikeGeometry: window 1900x250 at x = (primary width − 1900)/2, y = 0; Plate = window-relative (650, 8, 600, 56); probes at window-relative (710,36), (830,36), (950,36), (1070,36), (1190,36) — centres of 6x6 sentinel squares; WitnessFull = window-relative (600, 0, 700, 120); WitnessPartial = (900, 0, 260, 120) covering probes 3 and 4 only; SentinelRgb #FF00FF, CoverRgb #00FFFF.
</interfaces>
