2. `NativeMethods.txt`: SHCreateItemFromParsingName, IShellItem, IShellItemImageFactory, SIIGBF, GetObject, BITMAP, GetDIBits, BITMAPINFO, DIB_USAGE, DeleteObject, GetDC, ReleaseDC, CoInitializeEx, COINIT, plus what Task 2 needs (IShellLinkW, ShellLink, IPersistFile, SHParseDisplayName, CoCreateInstance, CLSCTX). 3. `ShellIcon.Get(parsingName, size, timeout)`: on a worker thread with the requested apartment (default MTA) call SHCreateItemFromParsingName -> IShellItemImageFactory.GetImage(size x size, SIIGBF_ICONONLY | SIIGBF_BIGGERSIZEOK); read pixels with GetObject + GetDIBits (top-down 32 bpp, negative height); DeleteObject the HBITMAP in finally; return IconResult(Width, Height, Bgra bytes, Elapsed, Error). A hard timeout abandons the worker thread (never joins indefinitely) and returns Error = "timeout".
4. `IconMetrics.Measure`: AllOpaque (every alpha 255), CornerAlphaMax (max alpha in the four 4x4 corners), StraightAlphaRatio (share of pixels with alpha < 255 where any colour channel > alpha — indicates straight alpha), FringeScore (after conversion to Pbgra32 compose over white and over black; mean luminance difference along the alpha 1..254 edge pixels). Convert Bgra32 -> Pbgra32 with FormatConvertedBitmap and Freeze() (STACK section 1).
5. `Program.cs`: CLI per the artifacts table; case `exe-notepad` = C:\Windows\System32\notepad.exe; append a CSV row to `--out` with columns case,kind,requested,width,height,all_opaque,corner_alpha_max,straight_ratio,fringe,ms,thread,ok,note; exit 0 when the case produced a bitmap, 1 otherwise.
  </action>
